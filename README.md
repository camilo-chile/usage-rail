# usage-rail (directory listing)

**Your Claude usage in a side panel, never on top of your chat. And what every prompt costs you.**

This branch is the Claude plugin directory listing for [usage-rail](https://github.com/camilo-chile/usage-rail). It holds one skill that explains what the widget shows and walks you through installing it.

The widget itself is a mod, and the directory accepts mods only from Verified organizations, so the widget installs from its author's marketplace:

- **Desktop app:** **+** next to the prompt box → **Plugins** → **Add marketplace** → `camilo-chile/usage-rail` → **Add plugin**.
- **Terminal session:** `/plugin install usage-rail --marketplace camilo-chile/usage-rail`

What it shows, in its own pane beside the conversation:

- **Context**: percent and tokens, with a **Compact** button that unlocks only when compacting is worth it.
- **5 hours** and **Weekly**: percent used, a live **+x%** for the message you just sent, time left and exact reset time.

Full description, screenshots and source: https://github.com/camilo-chile/usage-rail
